## Deviations / decisions (docs win over memory — verified against current docs)

1. **Prisma 7 architecture**: driver adapter (`@prisma/adapter-pg` + `pg`), explicit generator output path, `prisma.config.ts`, and `dotenv` are **required** by Prisma 7 — the current shape of the §11 "PostgreSQL + Prisma" choice, not new stack decisions.
2. **Better Auth adapter import** is `@better-auth/prisma-adapter` (the docs' install path); the CLI generated to a temp file with `--output` because default mode would have overwritten the domain models — merged by hand, keeping CLI output verbatim except the two reviewed adjustments above.
3. **Seed is `seed.mjs` (plain Node + `pg`), not `seed.ts`**: the generated Prisma client is TypeScript with extensionless imports, which plain Node cannot resolve; avoiding a TS-runner dependency (`tsx` is not in §11). If the seed grows complex, request `tsx` approval then.
4. **Local Postgres runs on host port 5433** — port 5432 was already occupied on Saiful's machine; `docker-compose.yml` + `DATABASE_URL` updated.
5. **Dev-only `.env`** now includes `BETTER_AUTH_SECRET` (random, dev), `ADMIN_EMAIL`, `ADMIN_PASSWORD` (placeholder — change before first real login). `.env.example` documents the shape.
6. `npm audit`: the 4 critical/high findings live in `@better-auth/cli`'s **nested** old `better-auth` copy (dev-only schema tool, never bundled/shipped). Top-level `better-auth@1.7.5` is patched. No action possible until upstream updates the CLI.
